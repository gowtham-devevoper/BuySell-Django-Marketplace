# BuySell - Django Marketplace

BuySell is a full-stack marketplace web application built with Django.

## Features

- User Authentication (OTP Login)
- Buy & Sell Products
- Cars
- Bikes
- Mobiles
- Laptops
- Properties
- Wishlist
- Chat System
- Seller Profiles
- Contact Unlock
- Search & Filters
- Responsive Design
- Admin Dashboard

## Technologies Used

- Python
- Django
- HTML
- CSS
- Bootstrap
- JavaScript
- SQLite

## Installation

```bash
git clone https://github.com/gowtham-devevoper/BuySell-Django-Marketplace.git
cd BuySell-Django-Marketplace
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
